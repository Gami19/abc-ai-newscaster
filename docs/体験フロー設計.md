## 体験フロー設計

### コンセプト一文
> **「10年後の未来を、きみがニュースで伝える」**
> ABCのスタジオに立ち、AIが生み出した未来原稿を読むキャスター体験

---

### 全体フロー図

```
【受付】
来場者がブースに到着
        ↓
【STEP 1｜入力】約30秒
名前・学年・夢・好きなことをタッチパネルで入力
        ↓
【STEP 2｜撮影】約20秒
Webカメラで顔写真を撮影
"ニュースキャスター風に座ってね！"
        ↓
【STEP 3｜AI生成】約15秒（待機画面）
GPT-4oが「10年後の未来ニュース原稿」を生成
"AIがあなたの未来を予測中…"
        ↓
【STEP 4｜プレビュー＆読み上げ】約40秒
・生成された原稿をテロップ表示
・TTSで読み上げ再生
・ニューステンプレートに顔合成されたプレビュー表示
        ↓
【STEP 5｜動画生成＆QR発行】約20秒
動画をS3に保存 → QRコード表示
"このQRで動画をもらえるよ！"
        ↓
【退場】
保護者と一緒にQRを読み込み・SNSシェア促進
```

---

### 1人あたりの想定所要時間

| フェーズ | 時間 |
|---------|------|
| 入力 | 30秒 |
| 撮影 | 20秒 |
| AI生成待機 | 15秒 |
| プレビュー・読み上げ | 40秒 |
| QR受け取り | 20秒 |
| **合計** | **約2分15秒** |

> 5台並列運用で1時間あたり約**260人**さばける計算

### 生成される「未来ニュース原稿」のイメージ

```
【2035年 ABCニュース】

こんばんは。キャスターの ○○ です。

本日のトップニュースです。
宇宙飛行士として活躍する ○○ さんが、
月面基地での新たな発見を報告しました。

○○ さんは子供の頃からサッカーと
宇宙が大好きで、その夢を見事に実現。

「あきらめなければ夢は叶う」と
地球に向けてメッセージを送りました。

以上、ABCニュースでお伝えしました。
```

### UX上の工夫

| 工夫 | 内容 |
|------|------|
| 待機を演出に変換 | AI生成中に「未来予測レーダー」風アニメ表示 |
| 保護者の巻き込み | プレビュー画面を横向きの大画面でも表示 |
| 失敗体験をゼロに | 入力は選択式中心・キーボード入力最小化 |
| 持ち帰り価値 | QR動画＋静止画サムネをセットで配布 |
| ABCブランド演出 | テンプレに「ABC NEWS 2035」ロゴ・チャイム音 |
