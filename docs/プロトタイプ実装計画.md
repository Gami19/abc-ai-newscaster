## プロトタイプ実装計画

---

### まず核心の問いに答える：バックエンドどうする？

```
GitHub public リポジトリで提出
  ↓
審査員がリポジトリを見てデプロイ or デモ確認する
  ↓
「環境構築が複雑すぎる」は避けたい
```

#### 選択肢の比較

| 選択肢 | 構成 | メリット | デメリット |
|--------|------|---------|-----------|
| A | Vercel API Routes のみ | 1リポジトリ・1デプロイで完結 | TypeScript縛り |
| B | Next.js(Vercel) + FastAPI(Render) | Python使える・設計通り | 2つのデプロイ管理 |
| C | AWS Lambda + API Gateway | 本番設計に近い | 審査員がAWS設定必要 |
| D | Docker Compose（ローカルのみ） | 環境完結 | 審査員がDocker起動必要 |

#### ✅ 推奨：**Option A（Vercel完結）+ ffmpeg.wasm**

```
理由：
├── 1リポジトリ・1デプロイで審査員がすぐ確認できる
├── Next.js API RoutesでOpenAI APIを直接呼べる
├── ffmpeg.wasm（WebAssembly）でブラウザ内動画生成
│     → サーバー側に動画処理が不要
│     → 顔写真がサーバーに送られない（セキュリティ◎）
├── Vercel無料枠で十分動く
└── .env.localにAPIキーを入れるだけで誰でも動かせる
```

### 技術スタック（プロトタイプ版）

```
【フロントエンド】
Next.js 14 (TypeScript, App Router)
├── TailwindCSS          スタイリング
├── Framer Motion        アニメーション演出
├── react-webcam         Webカメラ撮影
├── Canvas API           テンプレ＋顔写真合成
├── @ffmpeg/ffmpeg       ブラウザ内動画生成（WASM）
└── qrcode.react         QRコード表示

【バックエンド（Vercel API Routes）】
├── /api/generate        GPT-4o → 原稿テキスト生成
└── /api/tts             OpenAI TTS → 音声ファイル生成

【ホスティング】
└── Vercel               デプロイ・公開URL発行

【ローカル開発】
└── .env.local           OPENAI_API_KEY を設定するだけ
```

### 本番設計 vs プロトタイプ設計の対応表

| 機能 | 本番設計 | プロトタイプ（簡略化） | 理由 |
|------|---------|------------------|------|
| 原稿生成 | Lambda + GPT-4o | Vercel API Route + GPT-4o | 機能同等・実装シンプル |
| 音声生成 | Lambda + OpenAI TTS | Vercel API Route + OpenAI TTS | 同上 |
| 動画生成 | Lambda + ffmpeg | **ffmpeg.wasm（ブラウザ内）** | サーバー不要・プライバシー◎ |
| 動画保存 | AWS S3 + CloudFront | **ブラウザから直接ダウンロード** | S3設定不要 |
| QRコード | S3 URL → QR | **動画DLリンク → QR** | 機能的に同等 |
| 顔写真 | Canvas合成（送信なし） | Canvas合成（送信なし） | 変更なし |

### 4日間スケジュール

```
Day 1：基盤構築 + 入力・撮影
─────────────────────────────
□ Next.jsプロジェクト作成・Vercelデプロイ
□ TailwindCSS / Framer Motion セットアップ
□ 入力フォームページ実装（名前・学年・夢・好きなこと）
□ Webカメラ撮影ページ実装（react-webcam）
□ ページ遷移フロー実装（5画面）
□ ニューステンプレート画像作成（news_template.png）

Day 2：AI連携（原稿生成 + 音声合成）
─────────────────────────────
□ /api/generate 実装（GPT-4o 原稿生成）
□ GPT-4o system prompt チューニング
□ /api/tts 実装（OpenAI TTS 音声生成）
□ 生成待機アニメーション実装
□ プレビューページに原稿テキスト・音声再生を実装

Day 3：Canvas合成 + 動画生成
─────────────────────────────
□ Canvas APIでニューステンプレ＋顔写真合成実装
□ ffmpeg.wasm セットアップ
□ Canvas画像 + 音声 → mp4生成実装
□ 動画プレビュー再生実装
□ ブラウザダウンロード機能実装
□ QRコード生成・表示実装（qrcode.react）

Day 4：仕上げ + README + 最終確認
─────────────────────────────
□ UX調整（アニメーション・エラーハンドリング）
□ AI生成失敗時のフォールバック実装
□ .env.local.example 作成
□ README.md 作成（セットアップ手順・デモURL）
□ Vercel本番デプロイ・動作確認
□ GitHub public リポジトリ公開
□ PDF資料の最終調整
```
