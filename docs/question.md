# デジタル × コンテンツを軸にしたイベント施策の企画・設計（アーキテクチャ）

## 概要

朝日放送グループでは、ビジネスサイドからの要望に応え、短い開発期間で開発を行うことがしばしばあります。

様々な制約の中で要望をクリアするためには、日々新しい技術に触れて引き出しを持っておくことがとても重要です。

この課題では、アイデア力や自らのアイデアを短期間で形にするための技術的素養を確認します。

## 問題

「**デジタル × コンテンツを軸に、少し先の未来を子供達に体験してもらう**」というコンセプトのイベントに、ABCとして参加することになりました。

イベントには様々な業界の会社が参加していることもあり、「ABCならではの面白いことがやりたい。何かいいアイデアないですか？」とビジネスサイドから要望が来ています。

あなたはこの施策の技術担当チームの1人（チーフとあなたの2人組）として参加することになりました。

チーフから「まずは各自で案を出しましょうか」と言われています。以下の制約条件に基づき、**施策内容とそれにまつわるアーキテクチャ案**を作成してください。

| 項目         | 内容                                    |
| ------------ | --------------------------------------- |
| 対象属性     | 小学生とその保護者                      |
| イベント日程 | 3ヶ月後の5日間                          |
| 想定来場者数 | 期間を通して5万人                       |
| 会場概要     | 半屋外、電源・ネットワーク環境あり      |
| 予算         | 今回の課題では考慮せず                  |
| 備考         | AWSをはじめとするクラウド環境も使用可能 |
| NG事項       | 子供の教育を害するもの                  |

## 提出物

以下の内容を含む資料を **PDF形式** で `q3` フォルダの中に格納して提出してください。

1. 施策のコンセプト概要
   1. 子供・保護者にとっての魅力ポイント
   2. ABCならではのポイント
   3. 自分の思う「少し先の未来」ポイント
2. 体験のフロー
   1. 体験方法と得られる結果（例：図解 or ステップ説明）
   2. 1人あたりの想定体験時間
3. 技術構成（アーキテクチャ）
   1. 技術スタック（フロント / バックエンド / AI / 入出力管理 等）
   2. UX や セキュリティ面の工夫

図解（システム構成図、体験フロー図、画面遷移など）があると望ましいです。

なお、補足説明用のメモや図のソースファイル等を一緒に提出したい場合は、任意のファイル名で同フォルダに含めて構いません。プロトタイプの実装などを添えたい場合は、GitHub の public リポジトリの URLなどでの提出も可能です。
