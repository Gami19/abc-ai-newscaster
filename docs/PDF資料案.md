```
┌─────────────────────────────────────┐
│                                       │
│  コンセプト一文                         │
│                                       │
│  「10年後の未来を、                     │
│    きみがニュースで伝える」               │
│                                       │
└─────────────────────────────────────┘

■ 概要
  子供が自分の名前・夢・好きなことを入力するだけで、
  AIが「10年後の未来ニュース原稿」を生成。
  本物のニューステンプレートに顔写真が合成され、
  AIの声で原稿が読み上げられた動画を持ち帰れる体験。

■ 「少し先の未来」の表現
  └── 10年後（2035年）を舞台に設定
        → 現実感がある（遠すぎない）
        → 子供が自分ごととして想像できる距離感
        → AIが予測する、というナラティブが成立する

■ ABCならではの強み
  ┌──────────────────────────────────┐
  │ 放送局の資産          ×  最新AI技術  │
  │                                    │
  │ ・ニューステンプレート    GPT-4o      │
  │ ・キャスター文化          TTS音声    │
  │ ・報道・伝えるブランド   映像合成     │
  └──────────────────────────────────┘
```

## 03｜体験フロー

```
所要時間：約2分15秒 / 1人

 │ STEP 1｜入力           【約30秒】      │
 │                                       │
 │  タッチパネルで以下を入力               │
 │  ・ニックネーム                         │
 │  ・学年（ボタン選択）                   │
 │  ・将来の夢（自由入力 or 選択肢）        │
 │  ・好きなこと（自由入力 or 選択肢）      │
 └──────────────┬──────────────────────┘
                ↓
 ┌─────────────────────────────────────┐
 │ STEP 2｜撮影           【約20秒】      │
 │                                       │
 │  Webカメラで顔写真を撮影               │
 │  「キャスターっぽく座ってね！」          │
 │  3・2・1カウントダウン演出             │
 └──────────────┬──────────────────────┘
                ↓
 ┌─────────────────────────────────────┐
 │ STEP 3｜AI生成         【約15秒】      │
 │                                       │
 │  GPT-4oが未来ニュース原稿を生成        │
 │  待機中は「未来予測レーダー」アニメ表示  │
 │  「AIがあなたの2035年を予測中…」       │
 └──────────────┬──────────────────────┘
                ↓
 ┌─────────────────────────────────────┐
 │ STEP 4｜プレビュー      【約40秒】      │
 │                                       │
 │  ・生成原稿をテロップ表示               │
 │  ・TTSによる原稿読み上げ再生           │
 │  ・ニューステンプレート＋顔合成映像表示  │
 │  ・保護者向けに大画面でも同時表示       │
 └──────────────┬──────────────────────┘
                ↓
 ┌─────────────────────────────────────┐
 │ STEP 5｜QR発行         【約20秒】      │
 │                                       │
 │  動画をS3に保存 → QRコード生成・表示   │
 │  「このQRで動画をもらえるよ！」         │
 │  保護者がスマホで読み取り → 動画DL     │
 └─────────────────────────────────────┘

 ■ 回転率試算
   2分15秒 / 人 × 5台並列 = 約260人 / 時間
   1日10時間稼働 × 5日 = 最大13,000人対応（5台）
   → 台数を10台に増やせば最大26,000人 / 5日
```

## 05｜採用技術の選定理由

```
■ 設計の大方針

  本アーキテクチャは3つの制約から逆算して設計

  ① イベント期間限定（5日間）→ 運用コストを最小化
  ② 小学生ターゲット         → 体験レイテンシを最小化
  ③ 4日間でプロトタイプ      → 実装コストを最小化

  ┌────────────────────────────────────────┐
  │  「必要十分な技術を、最短で動かす」が核心  │
  └────────────────────────────────────────┘

─────────────────────────────────────────────

■ Canvas APIをフロントで使う理由
  → 顔写真をサーバーに送らない（プライバシー最優先）
  → サーバーラウンドトリップ分の待ち時間が消える
  → ブラウザ標準APIで追加ライブラリ不要

■ Lambdaサーバーレスの理由
  → 昼間だけ集中する負荷特性にEC2は非効率
  → リクエスト数に応じた自動スケール
  → 5日間限定 = 使った分だけ課金が最安

■ GPT-4o + OpenAI TTSで統一する理由
  → 同一SDKで原稿生成・音声合成が完結
  → コード量を最小化、バグリスクを低減
  → system promptで子供向けトーンを確実に制御

■ S3 + CloudFrontの理由
  → 5万人が同時にDLする負荷をエッジで分散
  → 署名付きURLで期限付きアクセス制御
  → ライフサイクル設定で7日後に自動削除

■ Vercelの理由
  → GitへのPushで即デプロイ
  → 4日間の開発中に何度でも反映可能
  → HTTPS・CDNが標準付属で設定不要
```

## 06｜セキュリティ・運用設計

```
■ セキュリティ設計

  項目              対策
  ────────────────────────────────────────
  個人情報          フルネーム不要・ニックネーム推奨
  顔写真            フロントのCanvasで完結・社外送信なし
  動画データ        S3保存・7日間で自動削除
  API Key           環境変数管理・フロントに非露出
  コンテンツ安全     GPT-4oのsystem promptで子供向け制約
  通信              全通信HTTPS・署名付きURL配信

■ 運用設計

  負荷想定
  ├── ピーク：5台並列 × 2分/人 = 約30人/分
  ├── Lambda同時実行数：20に設定
  └── S3転送量：10MB × 5万人 = 約500GB
               CloudFrontキャッシュで軽減

  障害対策
  ├── AI生成失敗時 → リトライ or デフォルト原稿を表示
  ├── 動画生成失敗時 → 静止画＋テキストで代替提供
  └── ネットワーク障害時 → オフラインモード（ローカル処理）
```

## 07｜プロトタイプ概要

```
■ プロトタイプの実装範囲

  ✅ 実装する機能
     - 入力フォーム（名前・学年・夢・好きなこと）
     - Webカメラによる顔写真撮影
     - GPT-4oによる未来ニュース原稿生成
     - ニューステンプレートへのCanvas合成
     - OpenAI TTSによる音声生成・再生
     - ffmpegによるmp4動画生成
     - S3アップロード・QRコード表示

  ⬜ プロトタイプでは簡略化する機能
     - グリーンバック合成（→ 静止画テンプレで代替）
     - 複数言語対応
     - 管理画面・分析ダッシュボード

■ 開発スケジュール

  Day 1  環境構築・UI設計・撮影機能実装
  Day 2  OpenAI API連携・原稿生成ロジック
  Day 3  Canvas合成・TTS・動画生成
  Day 4  統合テスト・デモ磨き・本資料作成

■ 動作確認環境
  - ブラウザ：Chrome最新版
  - デバイス：タッチパネル対応PC / iPad
```
